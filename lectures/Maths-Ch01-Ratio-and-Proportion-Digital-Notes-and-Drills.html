Basic Concept of Ratio & Word Problems

What is a Ratio?

A ratio is a mathematical comparison between two or more quantities of the exact same unit. It represents relative magnitude, never absolute values.
Example: If Salary ratio A : B = 3 : 4, A does not have ₹3 and B does not have ₹4. If cake is divided A : B : C = 2 : 3 : 4, total parts = 2 + 3 + 4 = 9 units. C receives double the cake of A, and A gets 2/9 = 22.22% of the entire cake.

The Unitary Scaling Method

When total amount T is distributed in ratio a : b : c:
Total units = a + b + c
1 unit value = T / (a + b + c)
Each person's share = (Number of units) × (1 unit value).

Key Properties, Degree Homogeneity & Types of Ratios

Degree Homogeneity Principle

If a/b = c/d = e/f = 2/3, then any linear combination (3a + 2c + 4e)/(3b + 2d + 4f) = 2/3 because the degree in numerator (1) matches degree in denominator (1).
Trap: If degree is different, e.g. (a + b + c) / a² (degree 1 / degree 2), the numerical value cannot be determined without scale factor!

Solving Coefficients via LCM

When given 25% a = 20% b = 10% c:
a/4 = b/5 = c/10 ⇒ a : b : c = 4 : 5 : 10.
When given 2a = 3b = 5c: divide by LCM(2, 3, 5) = 30 ⇒ a : b : c = 15 : 10 : 6.

Classification of Ratios (Formulas)

Duplicate: a² : b²
Triplicate: a³ : b³
Subduplicate: √a : √b
Subtriplicate: ∛a : ∛b
Inverse: 1/a : 1/b : 1/c
Compound: ac : bd

Ratio Merging & Componendo-Dividendo Rule

Ratio Merging Rule

To merge separate ratios like A : B and B : C, equalize the common variable B using its LCM.
Example: A : B = 4 : 5 and B : C = 2 : 3.
Multiply (A : B) by 2 ⇒ 8 : 10.
Multiply (B : C) by 5 ⇒ 10 : 15.
Merged Ratio: A : B : C = 8 : 10 : 15.

Componendo & Dividendo (C&D) Shortcut

If a/b = c/d, then (a + b)/(a - b) = (c + d)/(c - d).
Reverse Application (Speed Shortcut): If (a + b)/(a - b) = 7/1 ⇒ a/b = (7 + 1)/(7 - 1) = 8/6 = 4/3.

Class 6 Theory [Pages 27–35]

Proportion, Continued Proportion, Adding x & Variations

Proportion Foundations

• a : b :: c : d ⇔ a/b = c/d ⇔ ad = bc (Extremes = Means)
• Mean Proportional of a and b = √(ab)
• Third Proportional of a and b = b² / a
• Fourth Proportional of a, b, c = bc / a

Adding/Subtracting x Shortcut

Number x to add/subtract from a, b, c, d to form proportion:
x = |ad - bc| / |(a + d) - (b + c)|
= Difference of Products / Difference of Sums.

Direct & Inverse Variations

• Direct: y ∝ x ⇒ y = kx ⇒ y₁/x₁ = y₂/x₂
• Inverse: y ∝ 1/x ⇒ yx = k ⇒ y₁x₁ = y₂x₂
• Joint: y ∝ x/z ⇒ (y₁ · z₁)/x₁ = (y₂ · z₂)/x₂
