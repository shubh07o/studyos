🔄 Case 1: Reversal of Alphabet & Case 2: Opposite Letter Concept

Case 1: Reversal of Alphabet (Page 2)

  • The letters of the given base word are simply written in reverse order (Right to Left).
  • Step 1: Compare the base word and coded word to check if both contain the exact same letters.
  • Step 2: If the letters are identical, check the reversal pattern:
    FIGURE → ERUGIF  |  POLITICAL → LACITILOP

Case 2: Opposite Letter Concept (Pages 2–3)

Each letter is replaced by its opposite (mirrored) letter in the alphabet. The sum of any letter and its opposite is always 27:

Opposite Letter = 27 − Alphabetical Position

Examples:
• E5 → 27 − 5 = 22nd letter = V
• H8 → 27 − 8 = 19th letter = S

Cases 3 & 4: Increment/Decrement & Jumbling of Letters

Pages 3–4 • Forward/Backward Shifting (+n / −n) and Cross-Exchange Patterns + Q.5 to Q.10

📈 Case 3 & Case 4 Rules

Case 3: Increment / Decrement Pattern (Page 3)

The alphabetical position of each letter is increased (+n) or decreased (−n) by a fixed or alternating sequence of numbers to obtain the coded word.

• Example (PAGERS → QCHGSU): Alternating +1, +2, +1, +2, +1, +2.
• Example (CHEWER → HAJPJK): Alternating +5, −7, +5, −7, +5, −7.

Case 4: Jumbling / Cross-Shifting of Letters (Page 4)

Letters leave their original positions and move to new positions following a fixed geometric cross or swap pattern (sometimes combined with +1):

• Q.8 (ALIMONY → YILMNOA): 1st & 7th swap, 2nd & 3rd swap, 4th stays, 5th & 6th swap.
• Q.9 (STRONG → UTPSHO): Pairwise cross swap of (1↔2), (3↔4), (5↔6) with +1 added to each letter.
• Q.10 (HEALING → BFIKHOJ): 3-1-3 split cross with +1 on all letters.

Cases 5 & 6: Direct Substitution & Place Value Numbers

Pages 5–6 • Alphabet-to-Symbol/Letter Mapping & Numerical Operations + Q.11 to Q.16

🔢 Case 5 & Case 6 Rules

Case 5: Direct Alphabet / Number / Symbol Mapping (Page 5)

Identify common letters across two reference words and map each letter directly to its corresponding code character or symbol at the same index.

• Example (Q.11): From NUMBER = EPRSAY and SQUARE = NGPVYA, we directly extract M→R, E→A, B→S, R→Y to get MEMBER = RARSAY.

Case 6: Based on Place Value / Numbers (Pages 5–6)

Write the alphabetical positions (A=1 ... Z=26) of all letters and check for:

  • Sum of Place Values: CARE = 3 + 1 + 18 + 5 = 27 (Q.13)
  • Reversed Place Values Concatenated: RAT (18-1-20) → 20118 (Q.14)
  • Square of Letter Count: FOSTER (6 letters) → 6² = 36 (Q.15)
  • Vowels Same + Consonants Opposite: BIG → B(25) I(9) G(20) = 25920 (Q.16)

Practice Set I: Letter Rearrangement & Shifting Patterns

Pages 6–10 • Pairwise Swaps, Progressive Shifts (+1,+2,+3...), Wrap-Around (+8) & Reverse + Shift (Q.17 to Q.35)

🔡 Key Highlights in Q.17 – Q.35

Wrap-Around Rule (Q.28, Q.29): When adding +8 exceeds 26 (e.g., W(23) + 8 = 31), subtract 26: 31 − 26 = 5 (E).
Previous & Next Pair (Q.26): Each letter in TRUTH is replaced by two letters (−1 and +1), doubling the length of the coded word.
Reverse + Shift (Q.33, Q.34): Reverse the entire word first, then apply +1 to all letters (or middle letters).

Practice Set II: Cross Patterns, Direct Digits & Reverse Decoding

Pages 10–14 • Block Cross Shifts, Opposite + Cross, Greek Letter Substitution & Reverse Decoding (Q.36 to Q.54)

🔀 Key Highlights in Q.36 – Q.54

Block Cross & Opposite Cross (Q.41–Q.43)

• Q.41 (LIFETIME): Split into two 4-letter halves (LIFE | TIME), reverse each half, and add +1.
• Q.42 (EXTREME): First write the Opposite letters of the word, then swap the first 2 letters and last 2 letters.
• Q.43 (PLEADING): Split into two 4-letter halves; reverse 1st half with −1 and reverse 2nd half with +1.

Reverse Question Decoding (Q.52–Q.54)

Watch out for the phrasing: "Which word would be coded as X?" Here the coded word is given, and you must apply the inverse operation (−1 instead of +1, or −1, −2, −3...) to find the original base word.

Practice Set III: Vowel Indexing, Opposite Shifts & Digit Reduction

Pages 14–19 • Vowel Order (A=1..U=5), Opposite + Shift, Alphabetical Sorting & Digit Sum/Difference (Q.55 to Q.73)

🎯 Special High-Level SSC Patterns in Q.55 – Q.73

1. Vowel Rank & Vowel Count Suffix (Q.55–Q.57)

  • Forward Vowel Rank (Q.55): A=1, E=2, I=3, O=4, U=5, while consonants shift by −1.
  • Reverse Vowel Rank (Q.56): U=1, O=2, I=3, E=4, A=5.
  • Vowel Count Appended (Q.57): Shift all letters by −2 and append the total number of vowels at the end (e.g., TABLE → RYZJC2).

2. Digit Difference, Digit Sum & Squares (Q.68–Q.70)

  • Q.68 (PLANES): For 2-digit place values, take the difference of digits (e.g., P(16) → 6 − 1 = 5 (E)).
  • Q.69 (LOGITECH): Single-digit positions get −4; two-digit positions become the sum of their digits.
  • Q.70 (TABLEPADS): Single-digit positions are squared (B(2)² = 4 (D)); two-digit positions become the sum of their digits.

🧮 Key Formulas in Q.74 – Q.93

Odd Value Series (Q.78): Code = 2n − 1 (where A=1, B=3, C=5...).
Length Formula (Q.85): Code = (N − 1)² − 1 (where N = number of letters).
Scaled Position (Q.88): Code = (Pos − 1) × 5 (so A=0, I=40, K=50...).

Type 2: Coding Based on Renaming

Pages 30–31 • Real-World Fact Identification + Direct Name Substitution (Q.123 to Q.126)

🏷️ How to Solve Renaming Questions (Page 30)

  1. In this type, the names of objects are changed in a chain, but their real-world properties remain the same.
  2. Step 1: First answer the question using real-world general knowledge (e.g., What is the colour of milk? → White).
  3. Step 2: Look up what that real answer is called in the question statement (e.g., 'white' is called 'yellow' → Answer: Yellow). Never follow the chain further!

Type 3: Coding Based on Group of Words (Chinese Coding)

Pages 31–35 • Sentence Comparison, Common Word Elimination & Pattern Coding (Q.127 to Q.138)

💬 How to Solve Group of Words / Chinese Coding (Page 31)

Several sentences or phrases are given alongside their coded equivalents (where word order does not necessarily match code order).

  • Compare pairs of sentences that share a single common word and identify the single common code word between them.
  • Eliminate known words step-by-step to isolate the code for the target word(s).
  • Special Case (Q.133 & Q.138): If words are not repeated across sentences, check for a direct rule such as Word Length (birds are flying = 536) or First Letter + Length + Symbol (happy = H6#).

Type 4: Coding Based on Exception / Condition

Pages 35–38 • Digit/Symbol Lookup Tables with Conditional Override Rules (Q.139 to Q.145)

⚠️ How to Solve Conditional / Exception Coding (Page 35)

A base lookup table maps digits/symbols to letter codes, followed by 2 or 3 Exceptions / Conditions (e.g., "If the number begins and ends with an even digit, code both as #").

  1. First inspect the given target string against all listed conditions (checking first/last/nth elements for odd, even, zero, symbol, or perfect square).
  2. If a condition matches, apply the exception rule to the specified positions; otherwise, copy the normal code directly from the table.
